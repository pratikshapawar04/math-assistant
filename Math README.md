# 🧮 Math Assistant – CLI Problem Solver

## 📌 Overview

Math Assistant is a **menu-driven command-line application** developed in **C** that performs a variety of mathematical operations through an interactive interface. Users can choose from multiple options in a menu to solve common mathematical problems quickly and efficiently.

This project was created as part of an academic learning experience to strengthen programming fundamentals, problem-solving skills, and algorithmic thinking using the C programming language.

---

## ✨ Features

The application provides the following functionalities:

* 🔢 Check whether a number is **Even or Odd**
* 🔍 Check whether a number is **Prime or Composite**
* 📏 Find the **Absolute Value** of an integer
* 📋 Generate the **Multiplication Table** of a number
* 🧩 Find all **Factors** of a number
* ⬆️ Find the **Highest Factor** of a number
* 🔄 Reverse a number
* 🎓 Calculate **Student Grades** based on marks
* 🔢 Count the **Number of Digits**
* ➕ Calculate the **Sum of Digits**
* ✖️ Calculate the **Product of Digits**
* 🔵 Calculate the **Sum of Even Digits**
* 🟠 Calculate the **Sum of Odd Digits**
* 🧮 Calculate the **Factorial** of a number

## 🚀 Getting Started

### Prerequisites

* GCC Compiler (or any C compiler)
* Visual Studio Code (optional)

### Compile the Program

```bash
gcc math_assistant.c -o math_assistant
```

### Run the Program

```bash
./math_assistant
```

> **Windows**

```bash
math_assistant.exe
```
